# 在 iPhone 上安装预算日历

不需要安装 PWA 环境或其他 App。只需要一个已经部署到 HTTPS 的稳定网址。

## 安装到主屏幕

1. 在 iPhone 上用 **Safari** 打开预算日历网址。
2. 点 Safari 底部的 **分享** 按钮。
3. 向下找到并点 **添加到主屏幕**。
4. 保持 **作为网页 App 打开** 已启用。
5. 点右上角 **添加**。
6. 回到主屏幕，点“预算日历”图标启动。

首次联网打开一次后，应用外壳可以离线启动。账目保存在这台 iPhone 的 Safari 本地数据库中，不会自动上传到托管服务器。

## 备份到 iCloud Drive

1. 打开预算日历的 **设置**。
2. 在“备份与恢复”中点 **导出完整备份**。
3. 在 iPhone 的保存界面选择 **iCloud Drive** 和目标文件夹。
4. 保留生成的 `.json` 文件。文件含个人消费数据，请勿公开分享。

## 从备份恢复

1. 打开 **设置 → 备份与恢复**。
2. 点 **选择备份文件**，从 iCloud Drive 选择 `.json` 备份。
3. 核对恢复预览里的周期、账目和项目数量。
4. 点 **确认替换本机数据**。

恢复前应用会自动下载一份当前数据的安全备份。恢复操作会用所选文件替换当前设备里的全部预算日历数据。

## 避免数据丢失

- 不要在没有备份时清除 Safari 的网站数据。
- 更换 iPhone 或更换部署网址前先导出完整备份。
- 建议每个发薪周期结束后备份一次。
- 静态托管只提供应用代码，不保存或同步账目。
